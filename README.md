# 放置天堂 - 日出之國｜舒適版

以秋玥（shines871）的《天堂》放置同人遊戲為基礎，整合 pp771007 加掛，調整隊伍管理、能力說明、倉庫、戰鬥紀錄與存檔操作。

**舒適版 `v3.9.15` · 原版基底 `v3.8.34`**

[直接遊玩](https://lostshin.github.io/idle-lineage-class/) · [原始碼](https://github.com/lostshin/idle-lineage-class) · [秋玥原版](https://shines871.github.io/idle-lineage-class/) · [pp771007 加掛版](https://pp771007.github.io/idle-lineage-class/)

## 啟動遊戲

線上遊玩可直接開啟上述入口。本機預覽不需要 npm、建置流程或後端；安裝 Python 3 後，在專案根目錄執行：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

開啟 [本機入口](http://127.0.0.1:8000/index.html)，按「開始遊戲」。首次創角需填寫 1～12 字的角色 ID；按 `Ctrl+C` 關閉本機伺服器。

也可直接用瀏覽器開啟 `index.html`。線上網站、本機 HTTP 與 `file:` 的進度各自獨立；不同網域、連接埠、瀏覽器或使用者設定檔不會自動共用存檔。搬移進度請使用帳號匯出／匯入。

## 常用操作

### 查看能力與篩選戰鬥紀錄

- 點隊友或寵物名稱，切換「能力／裝備」查看目前資料；懸浮數值可查看加成來源。
- 在戰鬥日誌中使用「傭兵」旁的角色選單，只查看所選隊友的傭兵紀錄；其他來源仍由各自的小 tab 控制。
- 角色篩選限本次工作階段；切換角色或所選隊友離隊後回到「全部傭兵」。向上捲動可鎖定閱讀位置，按「回到最新」解除。

### 倉庫操作

1. 開啟倉庫，兩側分別顯示背包與倉庫，各自上下捲動。
2. 直接點物品名稱或圖示，轉移整疊。
3. 要轉移部分數量，點該列的數字，輸入不超過持有量的正整數。
4. 按「轉移此數量」或 `Enter` 直接交易；按 `Escape` 取消。編輯時點名稱不會轉移整疊，失焦也不交易。

交易成功會清除該列的本次數量；失敗則保留供重試。搜尋或切換分類會讓該側回頂端。視窗在本次工作階段重開時保留調整尺寸，重新載入後回到預設尺寸。

### 存檔與帳號搬移

網頁版進度保存在目前瀏覽器的本機儲存，沒有自動雲端帳號同步。搬移前先匯出備份並保留原始檔：

1. 回到角色選擇頁，也讓其他正在遊玩的角色分頁回到選角頁。
2. 按「匯入帳號」，選擇本版帳號檔、支援的加掛版完整備份，或一次多選舊版角色檔；帳號檔要單獨匯入。
3. 檢查角色位置、相同角色更新與不同角色的衝突選擇。
4. 確認共用資料還原範圍，再按「確認匯入」。共用資料也可能影響未匯入的現有角色。

帳號匯出始終涵蓋 **16 格角色**及支援的一般／經典倉庫、圖鑑、寵物、血盟／城堡、龍鑽等共用進度。關閉「16 格角色」只隱藏第 9～16 格，不刪除資料；舊八格帳號仍可匯入。

裝置縮放、可選加掛開關與工作階段鎖定不隨帳號搬移。網頁版與安裝版存檔格式分開，不能交互匯入；匯入失敗會依原流程回復資料，若回報回復失敗，保留匯入檔並重新載入確認。

### 離線收益如何生效

真正關閉頁面後重開，符合下列條件才會按同圖實戰樣本的 **70% 效率**結算，最短 1 分鐘、最多 12 小時：

- 離開前位於可離線狩獵的地圖；安塔瑞斯副本不適用。
- 同一地圖已累積至少 15 秒、3 隻擊殺的樣本，且最近 5 分鐘仍有擊殺。
- 該角色沒有正在擔任他人的傭兵。

摘要、完整戰利品與消耗記在系統日誌。未產生收益時，先查看日誌中的阻擋原因。切換分頁或縮小視窗但保留頁面時，走戰鬥補跑流程，與關頁離線收益分開。

## 開發與驗證

專案使用原生 JavaScript、共用全域狀態，沒有 `package.json` 或建置流程；`index.html` 決定 script 載入順序。本地檢查需要 Python 3、Node.js 與 Git。

### 修改前端資源

在專案根目錄執行：

```bash
python3 scripts/update-cache.py
python3 scripts/check-local.py
```

第一個指令更新前端資源 URL 的 SHA 快取版本。第二個指令檢查 JavaScript／測試語法、git 差異空白、資源版本、**69 個鏡像檔 SHA**及全部 `tests/*.integration.js`；目前通過時顯示 `13/13 passed`。

鏡像加掛檔與 `sw.js` 保留來源內容，整合差異放在本版模組。Node 整合檢查不代表瀏覽器版面與互動驗收。

### 執行瀏覽器 E2E

需要 Python 3、`ego-browser` CLI 與可連線的 Ego；runner 自行啟動測試伺服器，使用合成角色與隔離儲存。先選能重現需求的最小套件，不以重複整套測試取代針對性檢查。

查看參數並啟動一個保留的測試空間：

```bash
python3 tests/run-rwd.py --help
python3 tests/run-rwd.py --suite field-reports --protocol http --desktop-only --keep-space
```

`field-reports` 涵蓋安塔瑞斯背景、寵物能力、傭兵角色篩選與離線完整清單；隊伍標題使用 `party-header`。從輸出取得整數 `spaceId`，取代下面的 `SPACE_ID`；後續共用同一空間及 `p1`，不要並行啟動 runner。

程式交付前執行核心回歸；已有來源 SHA 相符的成功報告時先核對沿用：

```bash
python3 tests/run-rwd.py --space SPACE_ID --suite required --protocol both --desktop-only
```

`required` 依序執行 `rwd`、`ui-scale`、`gameplay`、`account-gameplay`、`companion-commands`。批次自動保留空間、遇錯即停；只接續失敗或受影響的套件。`visual-*` 必須緊接同一空間、同一協定的對應行為 fixture，例如 `--suite effect-details visual-effect-details`。

| 選項 | 用途 |
| --- | --- |
| 預設輸出 | 報告／畫面寫入 `tmp/test-runs/`，不納入提交。 |
| `--artifacts PATH` | 指定輸出目錄；相對路徑以專案根目錄為準。 |
| `--record` | 改寫入受追蹤的 `tests/artifacts/`，不能與 `--artifacts` 同用。 |
| `--skip-screenshots` | 略過圖片擷取，繼續行為檢查；需另核對代表性畫面。 |
| `--keep-space` | 單輪結束後保留空間；多套件／多協定批次自動啟用。 |
| `--soak-minutes N` | 設定 `ui-performance` 長測分鐘數；預設 30，`0` 只跑短測。 |

效能短測使用 `--suite ui-performance --soak-minutes 0`；長測另明確指定時長。通過必要檢查後停止，不追加無關套件。全部完成後，對該 TaskSpace 呼叫一次 `await task.finish({keep:[]})` 並等待完成。

測試不得使用真實角色或 iCloud 存檔。HTTP／file、桌面橋接替身與公開網站資源比對，都不等於安裝版或 iCloud 同步實測。

### 版本與發布

舒適版號由 [js/00-data.js](js/00-data.js) 的 `FORK_VERSION` 提供，登入頁會自動顯示；原作者的 `GAME_VERSION` 獨立保留。發布功能或修正時同步更新版號、README、版本斷言與資源快取；純文件修改不升版。

GitHub Pages 從 `main` 根目錄發布。推送後須確認該 commit 的 `pages build and deployment` 成功，再比對公開資源 SHA；推送成功不代表已上線。
